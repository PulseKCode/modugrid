6. Coded values

6-3. Names follow the value everywhere — search, CSV and copy

The code-and-name split is not applied in one place only. Cells, dropdowns, autocomplete, the filter popup, search, CSV export and the Excel copy all follow the same rule, so a file never comes out full of raw codes.

  • Type Active into the search box — it matches the readable name.
  • Open the Status funnel and the list reads the same way.
  • Press Export CSV and open the file — names, not codes.
  • Tick a row, press Copy for Excel and paste it — the same again.
