14-8. Translating the built-in messages (i18n)

The built-in wording is English. Pass options.i18n with just the entries you want changed and the rest stay as they are. A function value lets a message vary with the situation.

  • The left grid uses the built-in wording; the right has some entries replaced.
  • Press Undo on each and compare the messages.
  • Try Fit the column too — that message is built by a function.
