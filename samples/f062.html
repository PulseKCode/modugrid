8. Change tracking

8-4. An update carries only the fields that moved

Rather than the whole row, updated holds just the values that changed (alongside the id). It drops straight into the SET clause of an UPDATE, which keeps the server side short.

  • Change only the Name on one row.
  • Press Preview what will be sent — the name and the id, nothing else.
  • Change Score on the same row and it joins the payload.
