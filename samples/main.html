Codes in the data, names on the screen.

    

    

      Declare the lookup once on the column. The name is what people read and search and export;
      the code is what the database gets — the two need not look anything alike.
      No formatter and parser per column.

// one line on the column, and that is the whole setup
{ key:'status', label:'Status',
  options: [
    { code:'ACT', name:'Active'  },
    { code:'PND', name:'Pending' },
    { code:'CLS', name:'Closed'  },
  ] }

        

          Applies everywhere — the cell, the dropdown, autocomplete, the filter popup,
          search, CSV and the Excel copy. A file never comes out full of raw codes.

Lock a row, or just one cell.

    

    

      Approval screens are never all-or-nothing. Close a row once its status says so, and leave a
      single figure open to whoever owns it. Both are a function that returns true or false.
    


    

      

        

          Try it
          
            Closed rows are shut. Salary opens at a score of 80.
        

        

        

      

      


// the whole row
rowEditable: row => row.status !== 'CLS',

// or one cell, on the column
{ key:'salary',
  editable: (row, col) => row.score >= 80 }

        

          Applies to every route in — typing, Delete, paste and the row modal. It deliberately
          does not block updateRow(), so your own code can still apply a server response.
