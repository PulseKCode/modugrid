8.1 Image transfer

8.1-8. multipart — how the file parts are named

Each file is sent under the name img_{rowId}_{columnKey}_{index}. The first photo on row 3 arrives as img_3_images_0, and that is the name the server asks for.

  • Put one photo on each of two different rows.
  • Press Save.
  • The request body shows parts named img_<rowId>_images_0.
