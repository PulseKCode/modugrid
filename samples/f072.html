8.1 Image transfer

8.1-4. upload — sending each file as it is picked

The file goes to the server the moment it is chosen, and the {id, url} that comes back replaces it. When you save, only the reference travels, so a heavy set of photos does not make the save heavy.

  • Add a photo to a Photos cell — the upload starts straight away.
  • Progress is shown while it runs, and the server address replaces it when it finishes.
  • Press Preview what will be sent to see that only the reference goes.
