4. Selection

4-4. Select all covers the rows you can see

The header checkbox works on the rows currently rendered — the current page under ordinary paging, or the surviving rows when a filter is on. Rows you cannot see are never swept up by accident.

  • Tick everything on page 1 with the header checkbox.
  • Move to page 2 — nothing there is ticked.
  • Filter Role and select all; only the filtered rows are taken.
