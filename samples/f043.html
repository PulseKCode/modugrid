5.3 Input control

5.3-1. Forcing upper or lower case

textCase folds what the user types into upper or lower case. Use it to keep reference codes upper case and e-mail addresses lower case. It can be set on one column or across the grid.

  • Type abc into Code and it becomes ABC.
  • Type ABC@X.COM into Email and it becomes lower case.
  • Name is left alone, so it keeps whatever you type.
