8.1 Image transfer

8.1-7. multipart — data and files in one save

The files are held until you save, then the changes and the files travel together. Nobody leaves orphaned uploads behind on the server, which makes this the tidiest option when one save should do everything.

  • Add a photo — notice it does not upload yet.
  • Change a Name as well.
  • Press Save and both the changes and the files go at once.
