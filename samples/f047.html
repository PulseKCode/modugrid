6. Coded values

6-1. Codes in the data, names on the screen

This is the classic lookup-table arrangement — the code is stored, the name is shown. The shape of your option list hardly matters: {code,name}, {value,label}, {id,text}, {v,t} and plain strings are all recognised.

  • Each column declares its options differently, yet all of them show a readable name.
  • Open a cell and pick a different value.
  • Press Show the stored values to confirm the data holds codes.
