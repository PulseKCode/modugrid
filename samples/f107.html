14-3. Adding and removing photos

A type:'images' column holds photos. Pick them with ＋ Add or drop the files onto the cell. Hover a file name for a larger preview, and remove one with ✕.

  • Press ＋ Add on a Photos cell and choose an image.
  • Drag a file from your file manager onto the cell.
  • Hover a file name to preview it.
  • Remove a single photo with ✕.
