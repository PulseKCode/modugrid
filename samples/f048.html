6. Coded values

6-2. Deciding how a value reads (optionFormat)

Put placeholders such as {code} {name} into optionFormat to shape what appears. Any other field on the option object can be used too, so a department name or a headcount can travel with the value.

  • The same code reads differently in each column.
  • Department pulls in the dept and cnt fields as well.
  • Open a cell and the dropdown uses the same wording.
