6. Coded values

6-4. Typing to find a value in the dropdown

Open a cell, start typing and the list narrows. It matches on the formatted text, the display name and the code, so whichever of the three the user has in mind will find the entry.

  • Open the Status cell and type Act — matched on the name.
  • Clear it and type A — matched on the code.
  • Clear it and type [P] — matched on the formatted text.
