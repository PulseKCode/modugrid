5.2 Edit permissions

5.2-3. What a lock stops, and what it does not

A lock applies to everything the user does on screen. It deliberately does not block updateRow() and other programmatic calls, since your code still has to apply server responses and run batch updates.

  • On a locked row (status Inactive), try double-click, F2 and typing — nothing opens.
  • Select a locked cell and press Delete — it is not cleared.
  • Copy the text below and paste it onto a locked row — those cells are skipped.
  • Right-click → Edit Modal shows the fields read-only.
  • Change it from code goes through even so.
