7-2. The same check on every route in

Whether the value is typed into the cell, chosen from the calendar or saved from the modal, the check runs once and to the same rules. No route quietly skips it.

  • Double-click Note and type more than ten characters.
  • Type 150 into the Score cell.
  • Pick a date before 2000 from the Joined calendar.
  • Right-click → Edit Modal and save something invalid.
