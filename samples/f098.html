12.2 Fonts

12.2-1. Separate fonts for the header and the body

Size, family, weight and slant can be set for the header and the body independently. Give only the parts you care about and the rest is left alone; pass null for one property to reset just that one.

  • Bold header — the body is untouched.
  • 15px body — the header setting survives.
  • Clear the header weight — the size stays, the boldness goes.
  • Reset everything is setFont(null).
