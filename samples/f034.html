5.1 Entry points

5.1-2. One click, then type

Click a cell once and start typing — the input goes straight in, the way a spreadsheet behaves. There is no edit button to press first, and it works the same in row mode as in cell mode.

  • Click the Name cell once and type.
  • Press Switch to row mode and do the same — it behaves identically.
  • Composed scripts such as Korean or Japanese go in correctly from the first keystroke.
