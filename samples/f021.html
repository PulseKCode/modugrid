3.3 Search

3.3-1. Searching by code or by display name

search(q) sweeps several columns at once. For coded columns it matches both the display name on screen and the code stored underneath, so it finds the row whichever one the user remembers.

  • Type Active — matched on the visible text.
  • Type A — matched on the stored code.
  • Press Narrow the search to restrict it to particular columns.
