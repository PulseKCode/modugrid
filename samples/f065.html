8-7. Confirmation only when it cannot be undone

With soft delete there is a way back, so nothing is asked. Only softDelete:false, which removes the row on the spot, raises a confirmation. deleteRows() is a programmatic call and never asks either way.

  • On the left (soft delete) tick a row and use right-click → Delete — it is struck through at once.
  • Do the same on the right (immediate delete) and you are asked to confirm.
  • The Delete from code buttons below never ask, on either grid.
softDelete:true (default) — no prompt
softDelete:false — prompts first
