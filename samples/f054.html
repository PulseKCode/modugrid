6. Coded values

6-8. Reducing to codes before sending — toCode()

Data arriving from another screen sometimes carries the whole option object instead of the code. Send that as it is and the server receives [object Object]. toCode() pulls the code out; toCodeRow() returns a tidied copy and leaves your original untouched.

  • Rows 2 and 3 hold objects in Status on purpose.
  • Press Reduce to codes and read the result.
  • Values that are not codes at all, such as dates and arrays, pass straight through.
