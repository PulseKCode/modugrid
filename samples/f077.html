8.1 Image transfer

8.1-9. multipart — finding the file by ref, and leaving Content-Type alone

The ref on an image entry in the JSON is the file part name, so the server reads ref and asks for that part. One caution: do not set Content-Type yourself — the browser has to add the boundary along with it.

  • Add a photo and press Save.
  • Compare the ref in the JSON with the file part name.
  • Check that Content-Type is reported as set by the browser.
