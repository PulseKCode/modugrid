13. Server integration

13-3. The same question is not asked twice

Values for the filter popup (filterSource) and autocomplete candidates (acSource) are remembered once fetched. Ask for the same thing again and no request goes out, which keeps the chatter down.

  • Open and close the Role funnel a few times — the count does not rise.
  • Change the search term and the conditions differ, so a request goes out.
  • Type the same letters into the City cell repeatedly for the same effect.
