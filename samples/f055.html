7. Validation

7-1. Checking input without throwing it away

Attach a validate function to a column and the value is checked as it is committed. A value that fails is kept and the cell is simply marked red — wiping the input would leave the user with nothing to correct and no idea what went wrong.

  • Type 150 into Score and press Enter.
  • The cell turns red but 150 is still there.
  • Hover the red cell to read what is wrong.
  • Clearing Name and saving behaves the same way.
