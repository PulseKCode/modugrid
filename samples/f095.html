11. Modals

11-3. Read-only fields are still shown

A column marked editor:false appears in the window read-only. The value is not hidden — it is shown but cannot be changed — so reference details such as an employee number or a registration date stay in view.

  • Press Open the edit window.
  • Employee no. and Registered show their values but are not editable.
  • Everything else can be changed as usual.
