8. Change tracking

8-2. What submit sends — checking the JSON

This page shows exactly what leaves for the server. It arrives in three parts — inserted carries whole rows, updated is {id, changes} with only the fields that moved, and deleted is an array of ids. Coded columns go out as codes, and stray option objects are reduced on the way.

  • Change a few cells and add a row.
  • Press Preview what will be sent.
  • Check that Status leaves as A rather than Active.
  • Look inside updated for the changes object holding just the edited fields.
  • Send it prints the actual request body.
