6-7. Autocomplete settings — source, size and switching it off

Candidates come from the server (acSource) or from a local list (acHints). If the server does not answer, the local list stands in; a query already asked is not asked again. Columns that do not need it are switched off with ac:false.

  • Type M → Ma → Man quickly into Role — only one request leaves.
  • Clear it and type the same thing again — the count does not rise.
  • Turn on Simulate a server outage and type again — the local list appears instead.
  • The Note column has ac:false, so nothing is offered there.
