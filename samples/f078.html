8.1 Image transfer

8.1-10. multipart — files are released once the save succeeds

A successful save lets go of the original files. Nothing piles up in memory as you carry on working, and a photo already sent is not sent again with the next save.

  • Add a photo and press Save — the file goes with it.
  • Press Save again without touching anything.
  • This time you are told there is nothing to send.
