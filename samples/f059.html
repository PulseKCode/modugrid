8. Change tracking

8-1. Picking out what actually changed

Whatever the user did and however they did it, the grid compares the current state against the state it started from and reports only the differences. Cell edits, modal saves, insertions, deletions and even undo are all picked up.

  • Edit a cell — one update.
  • Right-click → Edit Modal and change something there; it is picked up the same way.
  • Add and delete a row as well.
  • Press Ctrl+Z and the counts come back down.
