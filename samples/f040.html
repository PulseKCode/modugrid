5.2 Edit permissions

5.2-1. Separate permissions for insert, update and delete

canInsert · canUpdate · canDelete split the three rights apart. Entries the user is not allowed to use disappear from the right-click menu, and without update rights the edit modal opens read-only instead.

  • Rebuild the grid with different combinations using the buttons.
  • Right-click a row to see how the menu changes.
  • With updates forbidden, double-clicking a cell does not open an editor.
