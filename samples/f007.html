2.4 Manipulating columns

2.4-2. A column key cannot be changed

updateCol() will change the label, width and type, but never the key. The key is the link between a column and the data, so changing it would break every value in that column. If you really need a different key, remove the column and add it again.

  • Change label and width is applied as you would expect.
  • Try changing the key applies the label and width but leaves the key alone.
  • The data keeps flowing, so nothing on screen breaks.
