5.3 Input control

5.3-2. Hints in empty cells (placeholder)

An empty cell can carry a hint such as Enter a name. There are three settings — every empty cell, the first row only, or nothing at all. Showing it on the first row keeps the screen calm while still explaining what belongs where.

  • It starts on every empty cell.
  • Switch to first row only and the hints below disappear.
  • Switch to nothing and they all go.
