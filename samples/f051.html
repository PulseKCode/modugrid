6. Coded values

6-5. A value outside the list is still accepted

Typing something the list does not contain stores it as typed, so nobody is blocked by a lookup table that has not caught up yet. The list itself is left alone, so the next time you open the cell you see the original entries.

  • Open the Role cell, type Architect and press Enter.
  • The value stays in the cell.
  • Open the same cell again — Architect is not in the list.
