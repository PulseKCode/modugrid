1. Basic structure

1-1. Creating a grid — one div is enough

Put an empty <div> on the page and call ModuGrid(selector, {cols}). The table, footer, popups, modals and toast are all built by the grid itself, so there is no markup for you to prepare.

  • The HTML of this page contains a single <div id="grid"></div>. Check the View source → Whole HTML tab below.
  • Load data with setData().
  • Press Load other data to feed the same grid a different set.
