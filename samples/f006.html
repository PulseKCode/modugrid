2.4 Manipulating columns

2.4-1. Adding, removing and changing columns from code

Columns can change without rebuilding the screen, which is what you want when the visible fields depend on a role or a search condition. A new column goes at the end, at an index, or before a named column.

  • Add Note — appended at the end.
  • Add Dept before Role — inserted where you ask.
  • Remove Salary — any sort or filter on that column is cleaned up with it.
  • Rename Name — changes the label and width only.
  • Adding several at once with addCols() redraws the grid a single time.
