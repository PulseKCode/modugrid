11. Modals

11-1. The detail and edit windows build themselves

These are the windows for viewing a row in full or editing it. There is no form to write — the fields come from the column definitions, so adding a column adds a field to the window as well.

  • Press Open the edit window and note the fields.
  • Close it and press Add a Phone column.
  • Open it again and the phone field is already there.
  • Right-click → Row Detail and Edit Modal open the same windows.
