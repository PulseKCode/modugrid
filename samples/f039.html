5.1 Entry points

5.1-7. A cleared number is empty, not zero

Clearing a numeric cell with Delete stores an empty value (null) rather than 0, because a server usually needs to tell "scored nothing" apart from "not filled in yet".

  • Clear one Score cell with Delete.
  • Type 0 into another one by hand.
  • Press Show the stored values and see that the two are different.
