3.2 Filtering

3.2-3. Finding a value in a long list

A column with many distinct values gets a search box at the top of the popup. While a search is active, Select all only touches the entries you can see, so anything hidden keeps its current state.

  • Open the City funnel — twenty values.
  • Type New into the search box and the list narrows.
  • Press Select all now and only the visible entries change.
  • Clear the search and the rest are still as they were.
