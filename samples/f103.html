13. Server integration

13-2. Loading state, failures and reloading

A loading overlay covers the grid while a request is out. If it fails, dataError tells you and the previous rows stay on screen, so a momentary error does not blank the table. reload() repeats the request with the conditions unchanged.

  • Press Normal request and watch the loading state.
  • Switch to Failing request and press Reload — the error is reported but the table survives.
  • Apply a sort or a search, then reload; the conditions are kept.
