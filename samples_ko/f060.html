8. 변경추적 · 전송

8-2. Submit 전송 데이터 — 서버로 나가는 JSON 확인

저장할 때 서버로 가는 내용을 눈으로 보는 화면입니다. 형태는 세 묶음입니다 — inserted 는 행 전체, updated 는 {id, changes} 로 바뀐 칸만, deleted 는 id 배열입니다. 목록 컬럼은 이름이 아니라 코드로 나가고, 옵션 객체가 섞여 있어도 코드만 뽑혀 나갑니다.

  • 셀 몇 개를 고치고 행도 하나 추가합니다.
  • 전송 내용 보기 로 서버에 갈 JSON 을 확인합니다.
  • 상태 값이 활성 이 아니라 A 로 나가는지 봅니다.
  • updated 안에 changes 가 있고 그 안에 바뀐 칸만 들어 있는지 봅니다.
  • 실제로 전송 을 누르면 전송 본문이 그대로 찍힙니다.
