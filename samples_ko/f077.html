8.1 이미지 전송

8.1-9. multipart — ref 로 파일 찾기 · Content-Type 은 건드리지 않기

JSON 쪽 사진 항목의 ref 값이 곧 파일 파트 이름입니다. 서버는 ref 를 읽어 해당 파일을 꺼내면 됩니다. 그리고 Content-Type 을 직접 지정하면 안 됩니다 — 구분자(boundary)까지 브라우저가 알아서 붙입니다.

  • 사진을 넣고 저장 을 누릅니다.
  • JSON 안의 ref 와 파일 파트 이름이 같은지 봅니다.
  • Content-Type 이 "브라우저가 자동 지정" 으로 나가는지 확인합니다.
