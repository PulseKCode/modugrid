# ModuGrid — 기능별 샘플 113종

`FEATURES.md`(2026-08-13판) 기준으로 만든 **사용자용 기능 안내**입니다.
영문판이 기본이고(`../samples/`), 이 문서는 한국어 선택본입니다. 파일 번호는 양쪽이 같습니다.
각 페이지는 독립 실행되며, 하단에 **소스 보기**(데모 JS / HTML 전체 2탭)가 붙어 있습니다.

---

## 실행

```
samples/index.html   ← 이 파일을 브라우저로 엽니다
```

왼쪽에 113개 목록, 오른쪽에 해당 샘플이 뜹니다.
상단 검색칸으로 기능을 찾고(`8.1` 처럼 절 번호로도 검색됩니다), `← 이전 / 다음 →` 으로 넘깁니다.
개별 파일(`f001.html` 등)을 직접 열어도 되고, `file://` 로 열어도 동작합니다.

문서의 체크 항목 146개 중 **사용자가 볼 필요가 없는 내용을 걷어내고 113개**로 정리했습니다.

| 주 기능이 아닌 부수 동작 설명 제외 | −5 |
| **최종** | **113** |

제외한 것은 두 부류입니다. 하나는 "전역 오염 없음", "드래그 중 재렌더 없음", "sticky 오프셋 실측"
처럼 개발 과정에서 문제를 잡았는지 확인하려고 적어 둔 항목입니다. 다른 하나는 기능이라기보다
**동작이 합리적임을 보이는 설명**입니다 — 오류 말풍선이 사라져도 오류 상태가 남는다거나,
메뉴 항목을 빼면 구분선도 함께 정리된다는 식의 내용이 여기 해당합니다.
매뉴얼은 주 기능만 다룹니다.
기능 자체를 설명해야 하는 것(컬럼 고정, 그룹 헤더 등)은 제외하지 않고
**사용자 관점으로 다시 썼습니다**.

## 페이지 구조

```
┌ 그룹 배지
├ 번호 + 제목 + 설명 (이 기능이 무엇이고 언제 쓰는지)
├ 확인 방법 (이 순서대로 눌러보면 되는 절차)
├ 데모 툴바
├ 실제 그리드
├ 로그 영역   ← 결과값이 실시간으로 찍힘
└ 소스 보기   ← [데모 JS] [HTML 전체] 탭 + 복사 버튼
```

두 탭 모두 **실제로 지금 돌고 있는 코드**라 복사해서 그대로 쓸 수 있습니다.

## 알아둘 점

- **서버 연동 · 자동완성** 항목은 `dataSource` / `filterSource` / `acSource` 를
  로컬 배열 + `setTimeout` 으로 흉내 냅니다. 지연은 동작을 눈으로 보려고 길게 잡았습니다.
- **submit** 항목은 `window.fetch` 를 가로채는 목(mock)을 씁니다.
  실제로는 `submit.jsp` / `upload.jsp` 주소를 그대로 넣으면 됩니다.
- **이미지** 항목은 로컬 이미지 파일을 직접 골라야 확인됩니다.
- 클립보드 항목은 `https` 또는 `localhost` 에서 더 안정적으로 동작합니다.

### 전송 데이터 형태 (자주 헷갈리는 부분)
